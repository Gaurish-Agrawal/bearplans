Chrome extension setup

From Workday courses to a schedule that fits.

For WashU Workday in Google Chrome on a computer. Keep using the website scheduler on other browsers and phones.

Your connection

Check the extension and this BearPlans server.

This check does not read courses or change anything in Workday.

  1. Install BearPlans

    {% if extension_store_url %}

    Open the Chrome Web Store listing, choose Add to Chrome, then confirm Add extension.

    Add to Chrome {% else %}

    The Chrome Web Store release is not available yet. You can try the preview with the manual installation below.

    Install the preview for testing
    1. Download the extension ZIP and unzip it into a folder you will keep.
    2. In Chrome, open the menu > Extensions > Manage Extensions, then turn on Developer mode.
    3. Choose Load unpacked and select the unzipped folder containing manifest.json.
    4. Reload this page and any Workday tab opened before installation.

    This preview has not been reviewed by the Chrome Web Store and does not update automatically. For updates, replace the files in the same folder, then reload the extension and its tabs.

    {% endif %}

    Open Chrome's Extensions menu and pin BearPlans. Return here to check the connection.

  2. Choose your courses in Workday

    Sign in through WashU. Go to Student Self Service > Academics Hub > Planning and Registration > Find Course Sections.

    Select the intended undergraduate academic period. Search for a course, open one result, and choose Add course to BearPlans. The extension collects the matching sections automatically. Repeat once for each course.

    Open WashU Workday →

  3. Generate and compare

    In the BearPlans panel in Workday, choose Generate schedules. Your results open here. Use Save above a result to keep it in this browser's Saved Schedules.

    Sections need meeting times to appear in a complete schedule. Workday is the source of current availability.

  4. Save a choice back to Workday

    Choose Add to Workday above the schedule you want. Enter a new name and confirm. BearPlans carries the academic period from your imported courses automatically. Sign in through Workday if prompted.

    Keep the Workday window visible while it finishes. BearPlans checks the sections, creates a new saved schedule, and verifies what was saved.

    This does not register you for courses or change existing registrations. Stopping midway may leave a partly filled new schedule; check it in Workday before starting again.

Need a hand?

The extension is installed but not connected

Reload this page after installing or updating. In Chrome's extension settings, make sure BearPlans is enabled and allowed on this site and WashU Workday.

Open the BearPlans extension popup > Connection settings. Set the server to {{ request.host_url.rstrip('/') }}, choose Save server, then Test connection. This is the site you are viewing now.

For local testing only, Use local server connects to http://127.0.0.1:5001 and asks for local access. The local server must be running. Public users should use https://bearplans.pythonanywhere.com.

I cannot add a course or generate a schedule

Use Find Course Sections for the intended semester and open one course result. Refresh Workday after an extension update. Check the message in the BearPlans panel; missing meeting times or no valid combinations can prevent generation.

A server error is different from a course error. Use Connection settings > Test connection first. If the public server is unavailable, please contact us.

A save to Workday paused

Use Open Workday in BearPlans to sign in or bring the save window back. Follow the displayed recovery message. Do not start a second save while the first is unverified; the new schedule may already contain some sections.
